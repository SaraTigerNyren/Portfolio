SARA TIGER NYRÉN – PORTFOLIO

1. Öppna ditt GitHub-repository Portfolio.
2. Välj Add file → Upload files.
3. Ladda upp index.html, projekt.html, projektdata.js och mappen bilder med alla bildfiler. Behåll sara.jpg som du redan har (eller ladda upp den från paketet).
4. Commit changes och vänta en kort stund på GitHub Pages.
5. Öppna https://saratigernyren.github.io/ och klicka på projekten.

VIKTIGT: Ladda upp bildfilerna i en mapp som heter exakt bilder, annars syns de inte. GitHub-webbgränssnittet kan hantera mappstruktur genom att du drar in mappen eller lägger till filer med sökväg.

Du ändrar innehåll i projektdata.js. För varje projekt: titel, introduktion, avsnitt, bilder. Alla bilder i detta paket kommer från dina uppladdade presentationer. Vissa är översiktsbilder och kan senare bytas mot separata högupplösta original.
